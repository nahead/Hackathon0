**Issue:** Outbound SMTP blocked by platform  
**Impact:** Cloud agent cannot send emails directly  
**Solution:** Hybrid approach (cloud detects, local sends)  
**Proof:** Email sending tested locally and working  
**Documentation:** See `PLATINUM_LIMITATIONS.md`

### 2. Social Media API Credentials
**Issue:** Requires external API account setup
