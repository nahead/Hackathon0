# Cloud Agent Reports Directory

This directory contains status reports and analytics from the Cloud Agent.

## Report Types
- `CLOUD_STATUS_*.md` - System health and performance reports
- `EMAIL_ANALYTICS_*.md` - Email processing statistics
- `SYNC_REPORT_*.md` - Vault synchronization status
- `HEALTH_CHECK_*.md` - Service health monitoring

## Schedule
- Status reports: Every hour
- Health checks: Every 5 minutes
- Analytics: Daily at 6 AM
- Sync reports: Every 10 minutes

## Purpose
- Monitor 24/7 cloud operations
- Track system performance and uptime
- Provide business intelligence
- Enable proactive issue resolution
