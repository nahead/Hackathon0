# Dashboard Update

Update the AI Employee Dashboard with current system status.

## Usage
Use this skill to refresh the Dashboard.md with current information about:
- System status
- Folder contents
- Recent activity
- Task statistics

## Instructions
You are updating the AI Employee Dashboard. Follow these steps:

1. **Check all folders** and count items:
   - Inbox/ - files waiting to be processed
   - Needs_Action/ - tasks requiring attention
   - Done/ - completed tasks
   - Pending_Approval/ - actions awaiting human approval

2. **Read recent log files** to get activity summary

3. **Update Dashboard.md** with:
   - Current timestamp
   - Folder status counts
   - Recent activity (last 5 actions)
   - System health indicators
   - Next recommended actions

4. **Calculate statistics**:
   - Total files processed today
   - Success rate
   - Average processing time (if available)

5. **Format the dashboard** clearly and professionally

Update the dashboard now with current system status.
