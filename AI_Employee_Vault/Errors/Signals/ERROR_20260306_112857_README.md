# Local Agent Signals Directory

This directory contains execution signals from the Cloud Agent to the Local Agent.

## Purpose
- Cloud agent creates signals for local agent execution
- Maintains work-zone separation (cloud drafts, local execution)
- Ensures secure delegation of approved actions

## Signal Types
- `EMAIL_SEND_*.md` - Email sending instructions
- `SOCIAL_POST_*.md` - Social media posting instructions
- `WHATSAPP_SEND_*.md` - WhatsApp message instructions
- `TASK_EXECUTE_*.md` - Task execution instructions

## Workflow
1. Human approves action in /Approved
2. Cloud agent creates execution signal here
3. Local agent monitors this directory
4. Local agent executes signal and moves to /Processed
